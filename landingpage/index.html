Workflow

Five steps.
Zero guesswork.

01

Prompt

Define your site in natural language or structured spec. Intent in, magic out.

02

Build

Agent executes through allowlisted tools only. WordPress, themes, plugins, pages—assembled.

03

Verify

CLI checks + real browser tests confirm the build matches expectations.

04

Self-heal

If verification fails, bounded repair cycles attempt recovery. Clear build report either way.

05

Export

Portable bundle ready for deployment. No vendor lock-in.

Trust by design

Constrained for your protection

Linopress doesn't run arbitrary code. Every operation is allowlisted. Browser navigation is restricted to local WordPress URLs. No Docker socket exposure. No secrets in model output. Controlled execution, not magic.
